Support

Need help with NexaHunter? Start with the checks below.

Sign-in problems

Return to the sign-in page and start a new Cloudflare OAuth session. If the OAuth client is still private, only authorized Cloudflare users can sign in.

Market-data problems

If quotes or charts are unavailable, the configured market-data provider may be unavailable or the production Worker secrets may not be configured.

Paper-order problems

Verify the symbol, quantity, price, buying power, and paper position. Duplicate orders are rejected intentionally.
